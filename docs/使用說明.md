# 短期活動排班系統（網頁版）使用說明

## 第一次使用
1. 用 Chrome 開啟程式網址（或桌面上已安裝的圖示）。
2. 按「選擇資料夾」，選一個放資料的資料夾（建議：文件 → 排班資料）。瀏覽器詢問時請選「允許」，若有「每次造訪時允許」更好。
3. 到「設定」頁籤新增崗位，再到「人員管理」頁籤新增人員並勾選適用崗位。

## 資料存在哪裡、要不要備份
- 所有資料自動存成所選資料夾裡的 `排班資料.json`，每次修改都會自動存，右上角會顯示「✓ 已自動存檔」。
- 每次開啟程式時，會自動把上一次使用結束時的資料備份到資料夾裡的 `備份` 資料夾，最多保留 10 份。**不需要手動備份。**
- 想還原：「設定」頁籤 → 資料夾與備份 → 在清單中挑一份按「還原此備份」。
- 請不要手動修改或刪除資料夾裡的 `排班資料.json`。

## 常見狀況
- **右上角出現「需要授權」或開啟時出現「需要您點一下授權」**：瀏覽器基於安全，偶爾會要求重新確認。按「授權並繼續」，在跳出的視窗選「允許」即可，資料不會遺失。
- **出現「已經有另一個視窗在使用本程式」**：請關閉其他已開啟的程式視窗或分頁，再重新整理。
- **出現「資料夾內的資料已被更改」**：代表這個資料夾同時被其他電腦（例如雲端同步）或其他程式更改過。請依畫面提示選擇「重新載入」或「覆蓋」。
- **想換電腦**：複製整個資料夾到新電腦，在新電腦開啟程式後選那個資料夾，原有資料就會出現。
- **瀏覽器**：請使用 Chrome（Edge 也可以）。Firefox、Safari 不支援自動存到資料夾。

## 建立活動與自動排班
1. 「活動專案」頁籤 → 「新增活動」。
2. 填活動名稱、每班時長（全活動一致）、工作日期與時間（可新增多天）。
3. 如果有午餐、晚餐等共同休息，勾選「有共同休息時間」並設定時段（預設沒有）。休息時間不排班，也不算連續上班。
4. 勾選本次所需崗位，設定每班需要幾人（預設 1 人）。
5. 勾選本次出席人員。
6. 按「儲存並產生班表」，等幾秒鐘就會看到班表、每人每天的班次統計，以及檢查結果。

排班規則：每個班次、每個崗位都有人；人員只會被排在適用的崗位；大家的班次數盡量接近；系統固定會盡量讓每個人做 1 休 1、避免連續上班（這項規則不能關閉）。
人力吃緊、無法避免連續上班時，檢查結果最上方會提示「本次人力吃緊，最長連續班次為 X 班」。
合格人數很少的崗位（例如只有 2 人會導播），會由這些人專任，不再輪其他崗位（專任設定預設「自動判斷」，也可以手動指定）。
最後剩餘時間不到一班的一半，會併入上一班（例如 7:30~20:00、每班 90 分，最後一班是 18:00~20:00）。

下次活動：選一個做過的活動，按「複製設定」，輸入新名稱與第一天日期，就會帶入原本的時長、工作時間、休息、崗位與出席人員（不含班表），再依需要微調即可。

## 目前版本包含的功能（第二階段）
人員與崗位管理、活動設定、複製活動、自動排班、班表與統計檢視、自動存檔與備份、安裝到桌面、離線使用、新版本提示。
手動換人、鎖定格子、定稿，以及 Excel 匯出與匯入，將在下一階段加入。
